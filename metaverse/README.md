# 우리마당

여러 사람이 같은 2D 마을에서 캐릭터로 걸어 다니며 채팅하는 가상 공간입니다.
ZEP처럼 쓸 수 있게 기능을 직접 만든 것이고, ZEP의 이름·그림·맵은 쓰지 않았습니다.

- 실행 주소(Claude 아티팩트): https://claude.ai/artifact/XjoxN3NdqXGuNZVzdMpJs4
- 소스: `index.html` 한 파일 (외부 라이브러리 없음, Google Fonts만 사용)

## 기능
- 타일 지도: 광장(분수), 회의실, 카페, 무대, 연못, 산책로
- 이동: 방향키/WASD, 지도·미니맵 클릭(길찾기), 휴대폰 조이스틱
- 채팅: 전체 / 근처(반경 7칸) / 같은 구역, 말풍선과 대화 기록
- 감정 표현 6종(숫자키 1~6), 참가자 목록(누르면 찾아가기), 확대·축소

## 실시간 접속 방식
서버 없이 Claude 아티팩트의 `room` 기능(presence)으로 위치·이름·최근 메시지 3개를 주고받습니다.
- 지금 링크를 열어 둔 사람끼리만 보입니다. 채팅 기록은 저장되지 않습니다.
- 들어올 수 있는 사람: 아티팩트를 공유받은 같은 조직 멤버와 초대된 사람.
  로그인하지 않은 사람이나 공개 링크로 들어온 사람은 실시간 기능에 연결되지 않고 혼자 둘러보기만 됩니다.
- '근처'·'같은 구역' 채팅은 화면 표시만 거르는 것이라 비밀 대화용은 아닙니다.
- 음성·화상 통화는 아티팩트 환경에서 WebRTC가 막혀 있어 넣지 않았습니다.

## 무료 웹사이트 버전 (GitHub Pages)
`docs/` 폴더가 GitHub Pages용 사이트입니다. Claude 로그인 없이 누구나 주소만으로 들어올 수 있습니다.
- `https://bonwonkr.github.io/kms/` : **본원초 메타버스**(공개용). 원본은 `metaverse/bonwon/index.html`.
  본원초 건물 1~5층·운동장·체육관, 탐험 미션·퀴즈, 화재 대피 훈련, 외벽 도색 공사 표시에
  여러 명 동시 접속(위치·이름·캐릭터 색·전체 채팅·리액션)을 더했습니다. 미션·퀴즈·대피 훈련 기록은 각자 기기에만 남습니다.
- 미니게임 **🎁 선물 상자 찾기 이벤트**: 왼쪽 막대의 선물 버튼(또는 아래 앱 메뉴)으로 시작합니다.
  3분 동안 1~5층과 앞마당·운동장에 놓인 상자 18개(황금 상자 1개는 3점)를 찾습니다.
  같은 방 사람에게 같은 자리로 함께 시작되고, 먼저 연 사람이 가져가며, 끝나면 순위가 나옵니다.
  상자 수·시간은 `GIFT_SEC`, `GIFT_PER_FLOOR` 값으로 바꿀 수 있습니다. 내 최고 기록만 기기에 남습니다.
- `https://bonwonkr.github.io/kms/village/` : 우리마당(위 마을 맵).
- 접속하면 닉네임·캐릭터 색·위치가 같은 방에 들어온 다른 사람에게 전달되고, WebRTC 특성상 서로의 IP 주소가 상대 브라우저에 보일 수 있습니다.
- 여러 명 접속은 [Trystero](https://github.com/dmotz/trystero) 0.26.0(MIT)으로 브라우저끼리 직접(P2P, WebRTC) 연결합니다.
  상대를 찾을 때만 공개 Nostr 중계 서버를 쓰고, 서버 비용·가입이 없습니다.
- 라이브러리는 `docs/trystero-0.26.0.mjs`로 저장소에 포함했습니다(CDN 의존 없음).
- 주소 끝에 `#방이름`(영문·숫자·하이픈)을 붙이면 다른 사람들과 섞이지 않는 별도 방이 됩니다. 예: `.../kms/#class3-1`
- 회사·학교 방화벽처럼 WebRTC가 막힌 네트워크에서는 연결되지 않을 수 있습니다(TURN 서버 미사용).

### 고친 뒤 다시 만들기
`metaverse/bonwon/index.html`(본원초) 또는 `metaverse/index.html`(우리마당)을 고친 다음 저장소 루트에서 `node metaverse/build.mjs`를 실행하면 `docs/`가 새로 만들어집니다.

### Pages 켜기 (저장소 설정, 한 번만)
GitHub 저장소(bonwonkr/kms) → Settings → Pages → Build and deployment
→ Source: **Deploy from a branch** → Branch: 이 코드가 있는 브랜치, 폴더 **/docs** → Save.
몇 분 뒤 `https://bonwonkr.github.io/kms/` 에서 열립니다.

브라우저에서 파일을 바로(file://) 열면 혼자 둘러보기 모드로 동작합니다.
